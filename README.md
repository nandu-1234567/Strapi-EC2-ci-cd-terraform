# Automate Strapi Deployment with GitHub Actions and Terraform

This project automates the deployment of a **Strapi application** using **Docker**, **Terraform**, and **GitHub Actions**. The pipeline builds and pushes Docker images automatically and deploys them on an EC2 instance via Terraform.



## Project Overview

* **CI Pipeline:** Automatically builds and pushes a Docker image when code is pushed to the `main` branch.
* **CD Pipeline:** Deploys the updated Docker image to an EC2 instance using Terraform.
* **Deployment Verification:** Strapi can be accessed via the public IP of the EC2 instance.



## Task Breakdown

### 1. CI/CD - Code Pipeline

The CI workflow runs whenever there is a push to the `main` branch. It performs the following actions:

1. Builds the Docker image of Strapi.
2. Pushes the Docker image to **Docker Hub** or **AWS ECR**.
3. Saves the image tag as an output for the Terraform CD workflow.



### 2. CD - Terraform Pipeline

The CD workflow is manually triggered and handles deployment. It performs the following actions:

1. Checks out the repository code.
2. Configures AWS credentials from GitHub Secrets.
3. Runs Terraform to provision the EC2 instance and deploy the Docker container.
4. Uses the Docker image tag output from the CI workflow to pull and deploy the Strapi container on EC2.



## EC2 Deployment Configuration

* EC2 instance is provisioned using Terraform.
* SSH access is enabled via a private key generated by Terraform.
* Security group allows inbound connections on **port 22** (SSH) and **port 1337** (Strapi).
* Docker is installed automatically.
* Strapi container is deployed dynamically using the Docker image from CI.



## Deployment Verification

After Terraform deploys the EC2 instance:

1. Retrieve the **public IP** from Terraform outputs.
2. Access Strapi in your browser at `http://<public_ip>:1337`.
3. SSH into the EC2 instance using the generated private key if needed.



## GitHub Secrets Required

* Docker Hub username
* Docker Hub password or personal access token
* AWS Access Key ID
* AWS Secret Access Key
